# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in this project,
please report it **privately** — do not open a public issue, pull request, or
discussion for it.

You can report in either of these ways:

1. **GitHub Security Advisories** — on this repository's **Security** tab,
   choose **"Report a vulnerability"** to open a private advisory visible
   only to you and the maintainer.
2. **Email** — send the details to **priyanshukumarthakur937@gmail.com**.

Please include, as far as you can:

- a description of the vulnerability and its impact;
- the affected version, file, or component;
- steps to reproduce, or a proof of concept;
- any suggested fix or mitigation.

## Disclosure window

Please allow up to **90 days** for the issue to be investigated and fixed
before disclosing it publicly. The maintainer will acknowledge your report,
keep you updated on progress, and credit you in the fix announcement unless
you prefer to remain anonymous.

## Scope

This policy covers the code in this repository. Vulnerabilities in
third-party dependencies should also be reported to their respective
projects; if one affects this project directly, a private report here is
still welcome.
